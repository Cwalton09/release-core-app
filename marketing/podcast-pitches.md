# Podcast and guest pitches

Each podcast appearance links back to release-core.com. Google counts those links as votes of trust, and AI tools like ChatGPT learn from show notes, which is how they start recommending Release Core.

**How to use this:** pick a show, copy the pitch that matches its angle, swap in the host's name and one episode you liked, and send it from releasecoremethod@gmail.com (or the show's form). Send 2-3 a week. If you don't hear back in 7-10 days, send the follow-up at the bottom once.

When you're booked, ask the host to link **release-core.com/what-is-release-core** in the show notes.
